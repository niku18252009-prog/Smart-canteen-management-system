# Project Statement

## Project Title
Smart College Canteen Management and Billing System

## Problem Statement
College canteens handle many small food orders every day. Calculating quantities and preparing the final amount manually can take time and may cause calculation mistakes.

The purpose of this project is to create a simple Python program that helps a canteen user select food items, enter quantities and calculate the total bill automatically.

## Scope
The project covers:
- Showing the available food menu
- Taking customer orders
- Accepting quantities
- Calculating item amounts
- Calculating the total
- Applying a simple discount
- Displaying the final bill

## Target Users
- College students
- Canteen staff
- Small college food counters

## Functional Modules
### 1. Menu Module
Displays food items and their prices.

### 2. Order Module
Allows the customer to select multiple items and quantities.

### 3. Billing Module
Calculates item amounts, total, discount and final amount.

### 4. Output Module
Displays the customer's final bill.

## Non-Functional Requirements
1. Usability - the program should be easy to operate.
2. Accuracy - bill calculations should be correct.
3. Reliability - invalid item numbers and quantities should be handled.
4. Maintainability - functions and lists make the code easy to change.
