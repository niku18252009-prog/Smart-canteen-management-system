# Smart College Canteen Management and Billing System

## Project Overview
This is a simple Python project for managing a college canteen order and preparing a bill.

The user can see the menu, select food items, enter quantities and get a final bill. A small discount is also calculated based on the total amount.

## Python Concepts Used
- Variables
- Input and output
- Lists
- for loop
- while loop
- if-elif-else
- Functions
- Arithmetic operators

The project is intentionally kept simple so that it matches the Python concepts covered in the student's current course.

## Main Features
1. Display canteen menu
2. Take multiple food orders
3. Store selected items and quantities in lists
4. Calculate item-wise amount
5. Calculate total bill
6. Apply discount
7. Display final bill

## How to Run
1. Install Python 3.
2. Open the project folder.
3. Run:
   python main.py

## Example
If the customer buys:
- 2 Samosas
- 1 Burger
- 2 Cold Drinks

The program calculates each amount, adds them together and displays the final bill.
