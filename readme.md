# Smart College Canteen Management and Billing System

## Project Overview

This project is a simple Python-based canteen management and billing system. It is designed to make the process of ordering food and calculating the final bill easier.

The program displays the available food items and their prices. The user can select the items they want, enter the required quantity, and the program automatically calculates the total amount. A small discount is also applied depending on the total bill.

## Python Concepts Used

This project uses the basic Python concepts covered in the course:

- Variables
- Input and output
- Lists
- `for` loops
- `while` loops
- `if-elif-else` statements
- Functions
- Arithmetic operators

The project has been kept simple and easy to understand so that it matches the Python concepts being studied in the course.

## Main Features

The program can:

1. Display the canteen menu
2. Take orders for multiple food items
3. Store the selected items and their quantities
4. Calculate the amount for each item
5. Calculate the total bill
6. Apply a discount when applicable
7. Display the final bill clearly

## How to Run

To run the project:

1. Make sure Python 3 is installed on your computer.
2. Open the project folder in your code editor or terminal.
3. Run the following command:

```bash
python main.py
```

The program will then display the canteen menu and you can start placing an order.

## Example

For example, if a customer orders:

- 2 Samosas
- 1 Burger
- 2 Cold Drinks

The program calculates the cost of each item, adds all the amounts together, applies the discount if applicable, and displays the final bill.
